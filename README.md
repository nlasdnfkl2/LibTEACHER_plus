# LIB-TEACHER — 학교도서관 장서 제적 판별 및 자동 출처 생성기

학교도서관 사서교사의 장서 제적(폐기) 업무와 독서·정보활용교육 수업 자료용 참고문헌 생성을 돕기 위한 네오브루탈리즘(Neo-Brutalism) 스타일의 정적 웹 도구입니다.

## 현재 구성 상태 (3-HTML 구조)

직전 요청에 따라 단일 탭 구조에서 **총 3개의 HTML 파일**로 분리·개선되었습니다.

- **`index.html` (입장 페이지)**
  - 네오브루탈리즘 스타일의 2분할 런처 화면 제공
  - `weeding.html`(장서관리 페이지) 및 `citation.html`(출처 관리 페이지)로 이동 지원
  - `?page=weeding` / `?page=citation` 쿼리 파라미터 리다이렉트 지원
- **`weeding.html` (장서관리 페이지)**
  - CSV · XLSX · XLS 장서 및 대출 통계 파일 업로드, 샘플 데이터 로드, 표준 CSV 양식 다운로드 지원
  - 기준 연도, 노후 경과 연수, 최대 누적 대출, 과다 복본 기준, 훼손 도서 우선 추천, KDC 000번대 참고도서 보호 제외 설정 가능
  - 도서관법 시행령 제적 상한(7.0%) 대조 및 상한 초과 시 원클릭 자동 축소(`7.0% 상한 이내로 자동 조정`) 지원
  - 행별 제적 사유 보충 메모 입력 및 사유서 CSV / XLSX / 인쇄(PDF 저장) 출력 지원
- **`citation.html` (출처 관리 페이지)**
  - 단행본(Google Books API), 학술논문(Crossref API / DOI), 웹페이지(URL) 메타데이터 조회 및 다중 후보 선택 지원
  - 한국문헌정보학회지, APA 7판, MLA 9판 참고문헌 및 본문 내 인용(In-text Citation) 생성·복사 지원
  - `localStorage` 기반 누적 참고문헌 목록 저장, 정렬, 일괄 복사, 삭제/초기화 지원

## 사용 방법

1. 세 파일(`index.html`, `weeding.html`, `citation.html`)을 같은 폴더에 둡니다.
2. 브라우저에서 `index.html`을 열어 원하는 작업 페이지로 이동합니다.
3. 메타데이터 자동 조회 및 외부 폰트/SheetJS 라이브러리 사용을 위해 네트워크 연결 환경에서 실행하는 것을 권장합니다(수동 입력 및 오프라인/로컬 파일 분석도 가능).

## 향후 확장 아이디어

- `weeding.html` 설정값 및 분석 상태의 `localStorage` 저장/불러오기
- `citation.html` 누적 참고문헌의 RIS / BibTeX / TXT / DOCX 내보내기
- GitHub Pages 배포용 저장소 구조 정리 및 샘플 데이터 추가
