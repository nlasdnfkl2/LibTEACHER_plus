# LIB-TEACHER // LibTEACHER_plus

> **Neo-Brutalism 스타일과 브라우저 로컬·외부 서지 연동을 결합한 학교도서관 장서관리·제적 판별 및 자동 출처 생성 웹 워크스테이션**

학교도서관 장서·대출 통계의 제적(폐기) 판별 및 사유서 산출과 수업·탐구용 참고문헌(한국문헌정보학회지 · APA · MLA) 생성·누적 관리를 단일 웹 환경에서 완결할 수 있는 사서교사·탐구 지원 웹 도구입니다.

- **배포 URL:** <https://nlasdnfkl2.github.io/LibTEACHER_plus/>

---

## 지금까지 완료한 작업

### 1. Neo-Brutalism 공통 UI & 인터랙션 셸 (`common.css`, `common.js`, `index.html`)
- **입장 허브 & 페이지 이동 (`index.html`):**
  - `01 · 장서관리 (`weeding.html`)` 및 `02 · 출처 관리 (`citation.html`)`로 바로 진입할 수 있는 허브 화면 구성
  - 상단 내비게이션 바를 통한 페이지 간 빠른 전환 및 인쇄(`@media print`) 전용 레이아웃 지원
- **테마 스타일 & 인터랙션 (`common.css`, `common.js`):**
  - 아이보리/크림 배경(`#fdfbf7`), 굵은 검정 테두리(`3px~4px solid #111111`), 오프셋 그림자, 옐로우(`#ffd83b`)·시안(`#48dbfb`)·그린(`#2ed573`)·핑크(`#ff4757`) 포인트 컬러 적용
  - 기본 브라우저 선택 목록(`select`)을 대체하는 **테마 맞춤형 커스텀 드롭다운 팝업**(`.lib-select-wrap`, `.lib-select-trigger`, `.lib-select-menu`) 및 외부 클릭·`ESC`·스크롤 닫기 지원
  - 마우스 글로우(`cursor-glow`), 커스텀 포인터/링, 카피레프트 푸터(`COPYLEFT 태양`) 및 개구리 이스터에그 토스트(`frog` 입력 또는 배지 5회 클릭) 탑재

### 2. 장서 제적(폐기) 판별 및 사유서 생성 (`weeding.html`)
- **파일 업로드 & 커스텀 엑셀 시트 직접 편집:**
  - `CSV`, `XLSX`, `XLS` 파일 드래그 앤 드롭/선택 업로드(SheetJS 기반 파싱) 및 표준 CSV 양식 다운로드 지원
  - 웹 화면에서 직접 셀 값을 수정하고 행을 추가(`+ 시트 행 추가`)하거나 삭제할 수 있는 **커스텀 편집 시트** 제공 및 변경 즉시 재판별 반영
  - 등록번호·출판연도·대출횟수 등의 이상치/누락 행을 자동 점검해 검증 알림 박스로 안내
- **특별 도서(폐기 X) 지정 & 법령·KLA 기준 판별:**
  - 시트와 판별 결과 테이블 양쪽에서 **특별 도서(`★ 폐기 X (특별)`)** 지정/해제를 지원하여 폐기 추천 대상에서 제외하고 별도 필터(`특별 도서(폐기 X) 보기`)로 확인 가능
  - 기준 연도, 노후 경과 연수, 최대 누적 대출 횟수, 과다 복본 기준, 오훼손·파손·분실 우선 추천, KDC `000`번대 참고도서 보호 설정 반영
- **도서관법 시행령 7.0% 제적 상한 대조 & 사유서 출력:**
  - 전체 기준 장서 수 대비 예상 제적·폐기율 KPI 및 게이지 표시, 7.0% 상한 초과 시 **7.0% 상한 이내 자동 조정** 기능 제공
  - KDC 대분류·추천/특별도서/전체 필터, 도서명/저자 검색, 행별 사유서 보충 메모 입력, **CSV / XLSX(요약 + 목록 시트) / 인쇄·PDF 저장** 출력 지원

### 3. 자동 출처 생성기 & 누적 참고문헌 관리 (`citation.html`)
- **다중 자료 유형 조회 & 엔터 키 검색:**
  - **단행본:** Google Books API + Open Library API 연동 검색(도서명, 저자, ISBN 지원) 및 일반 도서/에세이 검색 강화
  - **학술논문:** Crossref API 연동(DOI 번호 및 논문 제목 조회)
  - **웹페이지 / 온라인 기사:** URL 파싱 및 인용(접속)일자·도메인 정보 추출
  - 검색 입력창뿐만 아니라 **도서명** 및 **저자** 입력창에서도 `Enter` 키로 즉시 메타데이터 검색 실행
- **유사도 순위 후보 목록 & 사용자 선택 반영:**
  - 검색 결과를 임의 자동 입력하지 않고 **유사도 점수(`%`)와 순위(`#1`, `#2`...)**를 계산해 후보 목록으로 먼저 표시
  - 사용자가 원하는 항목의 **「이 자료 선택」**을 클릭할 때만 서지 입력란과 미리보기에 반영
- **양식 변환 & 누적 참고문헌 관리:**
  - **한국문헌정보학회지 양식**, **APA 7판 양식**, **MLA 9판 양식** 실시간 변환 및 본문 내 인용 문장 생성·복사
  - `localStorage` 기반 누적 참고문헌 목록 저장, 가나다/ABC 정렬, 개별 삭제, 전체 일괄 복사 및 목록 초기화 지원
