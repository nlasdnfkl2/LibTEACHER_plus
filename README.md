# LIB-TEACHER

> **Neo-Brutalism 데스크톱·워크스페이스 감성과 브라우저 기반 클라이언트 아키텍처를 결합한 학교도서관 장서 제적(폐기) 판별 및 자동 출처 생성 웹 도구**

학교도서관 사서교사의 장서 제적(폐기) 업무와 독서·정보활용교육 수업 자료용 참고문헌 생성을 한곳에서 처리할 수 있는 아카이브 워크스테이션입니다. 입장 페이지(`index.html`)를 통해 **장서관리 페이지(`weeding.html`)**와 **출처 관리 페이지(`citation.html`)**로 진입하여 통계 파일 판별·법정 상한 대조·사유서 출력부터 서지 조회·참고문헌 및 본문 인용 생성·목록 관리까지 완결할 수 있습니다.

- **배포 URL:** <https://nlasdnfkl2.github.io/LibTEACHER_plus/>

## 지금까지 완료한 작업 (v1.1 3-HTML 멀티페이지 · 제적 사유서 고도화 · 출처 목록 저장)

### 1. 네오브루탈리즘 입장 페이지 및 3-HTML 멀티페이지 라우팅
- **입장 런처 (`index.html`):**
  - `#fdfbf7` 크림 바탕, `#111111` 굵은 테두리와 오프셋 그림자, `#ffd83b`(옐로우)·`#48dbfb`(시안)·`#2ed573`(그린) 컬러 포인트를 적용한 2분할 런처 화면 구성
  - `weeding.html`(장서관리 페이지) 및 `citation.html`(출처 관리 페이지) 이동 카드 제공
  - `?page=weeding` 및 `?page=citation` 쿼리 파라미터 기반 즉시 리다이렉트(`window.location.replace`) 지원
- **페이지 간 상단 내비게이션 & 푸터 링크 (`weeding.html`, `citation.html`):**
  - 각 작업 페이지 상단바와 하단 푸터에서 입장 페이지(`index.html`) 및 상대 작업 페이지로 즉시 전환 가능

### 2. 장서 제적(폐기) 판별 및 사유서 출력 (`weeding.html`)
- **장서·대출 통계 파일 파싱 & 데이터 검증:**
  - `SheetJS (xlsx)` 기반 `CSV`, `XLSX`, `XLS` 파일 드래그 앤 드롭 및 파일 선택 업로드 지원
  - `등록번호`, `분류기호(KDC)`, `도서명`, `저자`, `출판사`, `출판연도`, `대출횟수`, `상태` 열 인식 및 샘플 데이터(`정상 + 이상치 포함`)·표준 CSV 양식 다운로드 제공
  - 도서명 누락 행 제외, 비정상 출판연도 노후도 판별 보류, 음수/오류 대출횟수 `0`회 보정 및 예외 로그 출력 지원
- **법령 및 KLA 폐기 판별 기준 엔진:**
  - `기준 연도`, `노후 경과 연수`, `최대 누적 대출`, `과다 복본 기준` 파라미터 설정 및 재분석 지원
  - `오훼손·파손·분실 상태 도서 우선 추천` 및 `참고도서(KDC 000번대) 자동 보호 제외` 옵션 제공
  - 공백·대소문자를 정규화한 동일 도서/저자 복본 집계 및 복합 제적 사유 태그 자동 부여
- **도서관법 시행령 7.0% 상한 대조 & 사유서 출력:**
  - 전체 기준 장서 수(직접 입력 모수 또는 업로드 권수 기준), 폐기 추천/선택 권수, 예상 제적률 및 진행 바 실시간 갱신
  - 법정 상한(7.0%) 초과 시 경고 표시 및 `7.0% 상한 이내로 자동 조정` 원클릭 축소 버튼 제공
  - KDC 대분류·추천/전체 보기·검색어 필터, 추천 일괄 선택/해제, 행별 **사유서 보충 메모** 직접 입력 지원
  - 요약 시트가 포함된 **사유서 XLSX**, UTF-8 BOM **사유서 CSV**, 인쇄/PDF 저장(`@media print` 최적화) 출력 지원

### 3. 수업·탐구용 자동 출처 생성기 (`citation.html`)
- **다중 자료 유형 메타데이터 조회 & 다중 후보 선택:**
  - **단행본:** Google Books API(`isbn:` 및 도서명 검색) 연동
  - **학술논문:** Crossref API(DOI 번호 및 논문 제목 검색) 연동
  - **웹페이지 / 온라인 기사:** URL 파싱을 통한 도메인·접속일자 자동 입력
  - 조회 결과 다중 후보 목록 제공 및 원하는 항목 클릭으로 입력 폼 즉시 반영
- **표기 양식 변환, 본문 내 인용 & 영구 목록 관리:**
  - `한국문헌정보학회지 양식`, `APA 7판 양식`, `MLA 9판 양식` 실시간 미리보기 지원
  - 전체 참고문헌 복사 및 **본문 내 인용(In-text Citation)** 생성·복사 지원
  - `localStorage`(`lib_teacher_bib_v1`) 기반 누적 참고문헌 목록 자동 저장, 가나다/ABC 정렬, 전체 일괄 복사, 개별 삭제 및 목록 초기화 지원
